# 總經邏輯鏈（2026-10-27）

首頁「多國重要總體經濟資料」的預設檢視改成邏輯鏈，原本按主題分卡的圖表移到「指標總表」分頁。

## 為什麼這樣排：由上而下（top-down）

個股的價格可以拆成兩件事：**獲利（EPS）× 市場願意給的倍數（本益比）**。總經對個股的影響，最後一定落在這兩件事，加上台股特有的資金來源：

| 焦點節點 | 影響個股的哪裡 | 圖表 |
|---|---|---|
| 折現率 → 本益比 | 倍數：實質利率上升，高本益比的成長股先被壓縮 | 美國 10 年期實質殖利率（TIPS） |
| 終端需求 → 營收 | EPS：電子業營收的上游需求 | 台灣出口年增、美國零售銷售 |
| 風險溢酬與資金 → 評價波動 | 倍數：市場要求的風險補償與可用資金 | 高收益債利差、Fed 淨流動性 |
| 匯率與外資 → 台股資金流 | 外資進出與出口商毛利率 | 銀行間美元兌新台幣 |

五條鏈各自從一個「起點圖表」出發，往右拆解原因（發散），每個分支最後都要連到上面四個焦點之一（收斂）：

1. **通膨與貨幣政策：** 核心通膨 → 上游成本（PPI）→ 油價；三者都連到 Fed 政策利率與 SOFR → 折現率。
2. **利率曲線與評價：** 美債殖利率曲線 → 曲線利差（→ 終端需求，倒掛轉正常領先需求放緩）、實質利率與通膨預期（→ 折現率；→ 黃金 → 風險溢酬）、歐英政策利率（→ 匯率）。
3. **流動性：** Fed 資產負債表與淨流動性 → TGA 與逆回購、全球 M2 → 台灣 M1B 與 M2；全部連到風險溢酬與資金。
4. **景氣、消費與信用：** 非農就業 → 失業率 → 零售銷售（→ 終端需求）→ 銀行逾期；非農 → 初領失業救濟金 → 信用利差 → 金融壓力指數；信用相關的都連到風險溢酬。
5. **台灣外需與匯率：** 台灣進出口（→ 終端需求）→ 美元指數（→ 匯率）→ 日圓與套利交易（→ 風險溢酬）。

每個焦點節點至少由兩條不同的鏈連入，這樣才是「收斂」而不是單一指標。

沒有放進來的資料：台灣 PMI／NMI 目前沒有資料（`TW_PMI`、`TW_NMI` 生產環境為空）；日本隔夜利率是月資料，不能和日圓日線畫在同一張圖，先不放；英國零售、台灣就業人數與央行資產負債表對台股科技股的傳導較間接，留在「指標總表」。

## 每個節點有什麼

- **圖表：** 沿用 `buildMacroTrendChart`，與指標總表同一套範圍按鈕、縮放與讀數。
- **要看什麼（question）：** 這張圖回答的問題。
- **分析：** 排程寫入的節點分析，存成 `productType=macro-node`、`code=節點 id 大寫`，有版本紀錄。第一行是「【判讀】順風／中性／逆風」（對台股科技股），網站讀這行顯示標記：順風紅、逆風綠，跟網站漲跌顏色一致。
- **下一步：** 每條連出去的線和傳導機制；點一下會捲到目標節點。滑鼠移到節點上，只亮出它的上下游。

## 改串法

連接方式全部在 `src/storages/macroLogicGraph.json`：

- `rows`：鏈的順序、標題與一句話主張。
- `nodes`：`row`、`stage`（第幾欄，0 是起點）、`series`（指標代碼，第一個是主線；`a|b` 表示有資料的第一個）。
- `focus`：收斂節點。
- `edges`：`from` → `to` 與傳導說明。

`tests/market/macroChains.test.ts` 會擋下不能畫或不收斂的圖：

- 不認得的指標代碼；
- 連到不存在的節點；
- 往左或同一欄的連線；
- 走不到焦點節點的節點；
- 重複的 id；
- 月資料和日資料放在同一張圖。

另外也檢查每條鏈只有一個起點，每個焦點至少由兩條鏈連入。改完跑測試，通過就能部署。排程每次都會重新讀 `GET /tymultiverse/api/market/dashboard/macro/graph`，新節點下次排程就會補上分析。
