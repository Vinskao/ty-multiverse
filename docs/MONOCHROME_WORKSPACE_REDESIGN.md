# 網站改版方向：黑白研究工作台與創辦人介紹

日期：2026-10-29

設計判斷與跨頁視覺原則另見 [DESIGN_PRINCIPLES.md](DESIGN_PRINCIPLES.md)，接手的 agent 修改頁面前應先閱讀。

## 設計目標

把全站收斂成黑、白與灰階的研究工具視覺：黑底與白底依既有主題切換，區塊用清楚的間距、細邊框與字級層次區分。行情漲跌色保留語意，資訊量不刪減；優先降低初始畫面的噪音，讓主要操作更快被看懂。

## 這輪落地

1. **投資工作台**：持倉清單與右側研究面板調成更均衡的欄寬；未選標的時，直接說明點選後可看的資料，不留一塊無說明的大空白。
2. **持股摘要**：保留表格、訊號及 Markdown／JSON 下載，移到主要工作台之後並預設收起。
3. **研究報告上傳**：保留多 PDF 同批上傳、每檔獨立送出及可見範圍；檔名自動作為標題。出版者、日期及自訂標題收進選填欄位。
4. **About**：增加「團隊介紹 → 創辦人」層級，保留履歷預覽／下載；人格特質與職涯概覽預設收起。移除重複的聯絡 CTA，避免跟首頁重覆。
5. **視覺系統**：導覽、主要按鈕及 About 卡片使用灰階色票；行情漲跌、風險方向等數據色仍用既有語意色。

## 後續階段

- 逐頁檢查研究、學習、API 文件、登入與 Palace 工具頁，將飽和色的裝飾性用法改成同一灰階 token，同時保留圖表分類色及狀態語意色。
- 確認寬螢幕工作台的持倉列、圖表和工具列比例；在手機上改為清晰的上下流程與可橫向滑動的分頁列。
- 把目前資料摘要與工作台主操作的視覺次序統一：先選標的、再查看資料、最後處理低頻明細。
- About 後續補團隊成員時，延續同一結構；不預先虛構不存在的成員或職稱。

## 驗收條件

- 主要操作區在桌面版有足夠圖表寬度，空狀態明確；手機版不產生整頁水平溢出。
- 摘要預設收起，但資料仍保留在伺服器產生的 HTML 與原始匯出端點。
- PDF 可一次多選；不填額外資料仍可送出，原檔名用為報告標題。
- About 清楚呈現團隊與創辦人父子層級，履歷預覽／下載仍可用，職涯概覽預設收起。
- About 不再出現紫色裝飾；頁面背景、卡片與主要控制符合黑白灰階視覺。
